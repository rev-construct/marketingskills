# Awesome Marketing Agent Skills

> Draft for [#499](https://github.com/coreyhaines31/marketingskills/issues/499). Meant to be published as its own repository under CC0, following awesome-list conventions. Entries below were checked to exist on 2026-11-11; descriptions are paraphrased from each repo's own description. Add a repo only if it is public, maintained, and does marketing or go-to-market work.

A curated list of skill packs and plugins that give AI agents marketing and go-to-market know-how.

## General marketing

- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills): about 50 skills for conversion, copy, SEO, paid ads, email, and growth, plus a tools registry and a Claude Code plugin marketplace. MIT.
- [ericosiu/ai-marketing-skills](https://github.com/ericosiu/ai-marketing-skills): open-source skills for growth experiments, sales pipeline, content ops, outbound, SEO, and finance automation. MIT.

## SEO and paid media

- [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo): an SEO skill for Claude Code with sub-skills and sub-agents covering technical SEO, E-E-A-T, schema, and AI-search visibility.
- [AgriciDaniel/claude-ads](https://github.com/AgriciDaniel/claude-ads): a paid-media operations skill for Claude Code across a dozen ad platforms.

## Go-to-market and sales

- [zapier/gtm-cheat-codes](https://github.com/zapier/gtm-cheat-codes): a field guide for go-to-market teams using coding agents, with installable skills for campaign planning, CRM context, and customer proof. MIT.

## Analytics and data

- [rudderlabs/rudder-agent-skills](https://github.com/rudderlabs/rudder-agent-skills): a Claude Code plugin marketplace for RudderStack: event instrumentation, tracking plans, transformations, and profiles.

## Directories

- [eliasstravik/open-source-gtm](https://github.com/eliasstravik/open-source-gtm): a community directory of public repos for GTM teams and GTM engineers.
- [travisvn/awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills): a general list of Claude skills, resources, and tools.
